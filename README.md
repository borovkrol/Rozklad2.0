# Розклад СС-25-1фмб-hm

## Публікація через GitHub Pages
1. Створіть **Public** репозиторій `rozklad`.
2. Завантажте в корінь репозиторію `index.html`, `manifest.webmanifest`, `icon.svg`, `sw.js`.
3. Відкрийте **Settings → Pages**.
4. У **Build and deployment** виберіть **Deploy from a branch**, branch `main`, folder `/(root)`, натисніть **Save**.
5. Через 1–3 хвилини відкрийте `https://ВАШ-АКАУНТ.github.io/rozklad/`.

На Android відкрийте сайт у Chrome → меню ⋮ → **Додати на головний екран** (або **Встановити додаток**, якщо такий пункт з'явиться).
